# Serein Select - 生活方式精选店

一个适合部署到 GitHub Pages 的响应式单页电商 Demo。项目用原生 HTML、CSS 和 JavaScript 实现商品展示、搜索筛选、购物车、收藏、库存校验和模拟结算，适合作为前端基础能力展示项目。

## 功能亮点

- 商品池包含 20 个商品，覆盖轻办公数码、通勤衣物、居家器物、食饮礼物、阅读书写和香氛个护等分类。
- 支持分类筛选、关键词搜索、价格排序和精选重置，筛选结果会实时刷新。
- 商品卡片展示价格、评分、库存、标签和图片，并支持收藏状态切换。
- 购物车支持加入商品、增减数量、移除商品、清空购物车和库存上限校验。
- 使用 `localStorage` 持久化购物车、收藏和今日销售数据，刷新页面后仍能保留操作状态。
- 模拟结算弹窗会汇总商品数量、订单金额和发货说明，确认后更新今日订单、销售额和目标完成率。
- 使用 CSS Grid、Flexbox 和媒体查询适配桌面端、平板和手机屏幕。

## 技术栈

- HTML5 语义化页面结构
- CSS3 响应式布局、卡片式 UI、交互动效
- 原生 JavaScript 状态管理和 DOM 渲染
- Font Awesome 图标库
- Unsplash 远程商品图片
- GitHub Pages 静态部署

## 本地运行

直接打开 `index.html` 即可预览，也可以使用静态服务运行：

```bash
npm start
```

## 验证

项目包含一个轻量静态检查脚本，用于确认 README、页面 SEO、购物车持久化、收藏持久化、库存评分和结算弹窗等关键内容存在：

```bash
npm test
```
